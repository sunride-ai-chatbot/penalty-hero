# Penalty Hero

משחק פנדלים עצמאי לטלפון: שחקן מצולם, דשא מצולם, קהל וידאו, שם ומספר דינמיים על החולצה, בחירת מדינה ← ליגה ← קבוצה, משחק מול המחשב או מול חבר באמצעות קישור.

נבנה מתוך `sunride-ai-chatbot/goalassoMANAGER` בגרסה `96321f70e497d9eba9f73ff0354a4784fbd9b2d9`. הפרויקט עומד בפני עצמו: אין iframe, אין מסכי קריירה, אין תלות בדומיין `goal-m.com`.

## הרצה

```
npm start            # http://localhost:5173/  (שרת סטטי, אין תלויות להתקנה)
npm test             # 29 בדיקות יחידה: חוקים, דו־קרב, פרוטוקול רשת, נתונים
npm run test:e2e     # 6 בדיקות דפדפן (דורש Playwright ו־Chrome)
npm run build        # dist/ — תיקייה סטטית שאפשר להעלות לכל אחסון
npm run catalog -- <נתיב ל־checkout של המקור>   # בנייה מחדש של data/ מקובצי הסגלים
```

כניסה ישירה: `index.html` (מסך הפתיחה). הזמנה: `?room=CODE`. מצב בדיקות: `?debug=1` (FPS, קליפ, פריים, פריים המגע, עוצמה, בועט, כיוון שוער, תשעת אזורי היעד). תצוגה פשוטה בכפייה: `?view=2d`.

## טעינה

האצטדיון נטען מראש כבר ממסך הפתיחה (`assets/penalties29/demo3d/preload.js`): קוד התלת־ממד, אטלס הבעיטה, הדשא והיציע נשמרים במטמון התמונות של three.js בזמן שבוחרים קבוצה. הבעיטה הראשונה מחכה רק לתנועת הבעיטה; תגובות השמחה/ההחמצה, וידאו הקהל ותמונות השחקנים נטענים ברקע. `node dev/loadtime.mjs` מודד מה נטען אחרי הלחיצה על „לנקודה הלבנה”.

## מיפוי סגל, שם, מספר ומדים

שלוש ישויות נפרדות: **משתתף** (השם שהוקלד; מופיע רק בלוח התוצאות), **מועדון** (מזהה קבוע, צבעים, סגל) ו**כדורגלן** (מזהה יציב `club#index`, שם, עמדה, מספר, דירוגים).

- `scripts/build-catalog.mjs` קורא את `data/*.json` ו־`data/euro/*.json` של המקור ואת הגדרות המועדונים שבקוד המקור, בלי להריץ את קוד המקור. מודל הדירוג, המאפיינים, ההרכב והמספרים הוא העתקה דטרמיניסטית של חוקי המקור.
- **מספרים:** אין מספר רשמי בקובצי המקור, ולכן כל המספרים הם הקצאת הסגל של המשחק (`noSource: "assigned"`), יציבה ואינה מוגרלת מחדש. אם יתווסף שדה `no` לקובץ סגל, הוא יועבר כמו שהוא (`noSource: "data"`).
- **סדר בועטים:** עשרת שחקני השדה של ההרכב הטוב ביותר לפי מיומנות בעיטה, והשוער אחרון; חוזר אחרי סבב מלא. ברשת שני הטלפונים מאמתים hash של הסגל לפני תחילת המשחק.
- **על החולצה:** שם הכדורגלן (שם משפחה כשהשם המלא ארוך) והמספר שלו, נצבעים מחדש לכל בועט ועוקבים אחרי `labels` שבכל פריים. צבעי המדים מוחלפים בשיידר לפי גוון (צהוב המפתח ← חולצה וגרביים, כחול המפתח ← מכנסיים), עם שמירת קפלים ותאורה.
- 301 מועדונים, 8,299 שחקנים. מועדון בלי 14 שחקנים בנתונים אינו מוצג.

הערה: בגלל שהמזהים במקור תלויים בסדר יצירה בזמן ריצה, ערכי המיומנות כאן אינם זהים ספרה־בספרה למשחק המקורי, אבל הם נגזרים מאותם נתונים באותן נוסחאות.

## תמונות שחקנים

ליד שם הבועט מוצגת התמונה שלו. `scripts/build-catalog.mjs` משייך לכל שחקן את התמונה מ־`data/visuals/` של המקור, ורק אם ביקורת התמונות של המקור סימנה אותה `ok`; חבילות התמונות (`assets/facepacks/*.json`, אחת לכל מועדון) מועתקות בלי שינוי ונטענות רק למועדונים שמשחקים. ל־2,346 מתוך 8,299 שחקנים יש תמונה; לשאר מוצג עיגול בצבע הקבוצה עם מספר החולצה. רוב התמונות מ־Wikimedia Commons ברישיונות CC שמחייבים ייחוס: הקרדיט (צלם ורישיון) שמור בתוך כל חבילה ומוצג בהקשה על התמונה.

## מה שונה מהמקור בחוקים

- פונקציה אחת (`resolveKick`) לכל המצבים: מול מחשב, ברשת, כשאני בועט וכשאני בשער.
- חלון הדיוק כולל את איבר השוער גם מול המחשב.
- השוער מתחייב פעם אחת: קריאה מותרת רק בבעיטה איטית ולפני הניתוק מהקרקע.
- תשעה כיווני שוער (נוסף „נשאר באמצע”), והבועט מכוון לנקודה רציפה ולא לאזור.
- **גרסה 1.2 (חוקים 12):** השוער קופץ לנקודה המדויקת שאליה שחררת את העיגול ולא לאחד מתשעה אזורים. בעיטה מסובבת (כפתור „עיקול”): מתפזרת יותר ומקשה על השוער. כדור שפוגע בקורה מבפנים נכנס בכ־30%. הבועט הוא שמאלי או ימני לפי השחקן (אותו קליפ מצולם, הפוך), אורך הריצה משתנה ולפעמים יש היסוס לפני הבעיטה, מהזרע של הבעיטה. בבעיטה המכריעה ובהכרעה הסמן מהיר ב־12% ויש דופק אדום בשולי המסך.
- פרוטוקול רשת גרסה 3 (SHA-256 במקום `pcupHash`; הבחירה של השוער היא נקודה, של הבועט כוללת עיקול), ערוץ `phero:CODE`. **אינו תואם לחדרים של המשחק המקורי.**

## הגדרת משחק הרשת

`config/network.json` מגיע עם `"transport": "none"`, ולכן המשחק מציג „משחק ברשת לא מוגדר” ולא יוצר קישור. להפעלה, העתיקו את `config/network.example.json` ומלאו כתובת פרויקט Supabase ומפתח **publishable** בלבד (מפתח service-role נדחה). נדרש Realtime Broadcast בלבד, בלי טבלאות.

להחלפת שרת: כתבו ב־`src/net/transport.js` פונקציה `connect(code, onMessage) → {send, close}` והחזירו אותה מ־`loadTransport`. הפרוטוקול אינו תלוי בשירות.

ההכרעה מחושבת בשני הלקוחות. ההתחייבות מונעת הצצה בבחירת היריב, אבל אין שרת שופט: לקוח שעבר שינוי יכול להתחייב לכל כיוון שירצה.

## עדכונים

- **מדיה:** החליפו קובץ באותו נתיב. שינוי באטלס הבעיטה מחייב לעדכן יחד את `floors`, `contactX` ו־`labels` ב־`clips.json` (הבדיקות מאמתות אורכים). קליפים כיווניים נוספים: הוסיפו מפתח ל־`clips.json` ומיפוי ב־`filmed-taker.js`.
- **קבוצה או שחקן:** ערכו את קובץ הסגל במקור והריצו `npm run catalog`. ה־hash של הסגל וגרסת הקטלוג משתנים לבד.
- **גרסה:** עדכנו את `VERSION` ב־`src/version.js` וב־`sw.js` (הבנייה נכשלת אם הם שונים).

## פערים ידועים

- **לא נבדק על מכשיר פיזי.** כל הבדיקות רצו ב־Chrome headless על Linux עם WebGL בתוכנה (כ־3–5fps), ולכן אין מדידת ביצועים אמיתית, ואין אישור ל־Safari באייפון או ל־Chrome באנדרואיד.
- **רשת מול Supabase אמיתי לא נבדקה.** הפרוטוקול נבדק עם שני לקוחות דפדפן אמיתיים דרך BroadcastChannel ועם אוטובוס בזיכרון.
- **השוער** הוא וידאו מצולם בתיקייה `assets/penalties29/keeper/`: עמידה, קפיצה למרכז, זינוק נמוך, אמצעי וגבוה שמאלה (ימינה הפוך), ואכזבה אחרי גול. הדמות התלת־ממדית נשארת גיבוי אם הקבצים לא נטענו. הקליפ נבחר לפי גובה הידיים. קליפ חסימה נמוכה עם כדור ביד התקבל ולא חובר, כי הכדור שבתוך הקליפ היה מופיע גם בגול.
- **חגיגה** אחרי בעיטה מכרעת (גול או החמצה): סרטון של כל הקבוצה מתחבקת (כ־7 שניות, מוגדל ב־20%), בלבן, כשצבעי החולצה, המכנס והגרביים של הקבוצה המנצחת נצבעים עליו בשיידר (`assets/penalties29/party/`). נוגעים במסך כדי לדלג.
- **העיקול** נקבע מקשת באצבע בזמן הגרירה, ללא כפתור.
- **תנועת בעיטה אחת** (`highL`) לכל הכיוונים; בועט שמאלי הוא אותה תנועה הפוכה, לא צילום נפרד.
- **רענון באמצע משחק רשת** מסיים אותו: הצד השני מקבל הודעת ניתוק אחרי 30 שניות. המסך נשאר דלוק בזמן דו־קרב (Wake Lock, היכן שנתמך) והדפדפן מזהיר לפני סגירה.
- **אין שרת שופט:** הדירוג והסטטיסטיקה נשמרים בטלפון בלבד.
- **סאונד** לא שונה בגרסה 1.2.
- **שמע** לא נבדק בהאזנה.
- בחלק מקובצי המקור שם השחקן בעברית הוא בעצם באנגלית, ובליגה א׳ העמדה והשווי מסומנים במקור כ־generated.
